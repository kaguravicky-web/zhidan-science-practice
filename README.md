# P3 Science Practice (Classification)

Home practice page for a Primary 3 science pupil (Singapore syllabus, Diversity / Classification).

- `index.html` is the whole app: no build step, no dependencies.
- Tabs: Learn (key-fact cards), Quiz (3 MCQ sets of 10), Charts (flowchart and table questions with model answers and a keyword checklist; the parent marks each answer), Mistakes, parent guide.
- Progress is kept in the browser's localStorage (`sci3-*` keys).
- All charts and questions are written for this page.
